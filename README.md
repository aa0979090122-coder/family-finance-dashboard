# 家庭財務儀表板

網站：https://aa0979090122-coder.github.io/family-finance-dashboard/

公開檔案只有應用程式與空白登入設定，不含家庭帳務或規劃金額。登入指定 Google 測試帳號後，登入時讀取私人試算表，儲存時另行請求編輯權限；授權憑證只保留在瀏覽器記憶體。

- 實際記帳：原本的年度支出分頁。
- 規劃初始值：私人「網站模型」分頁。
- 網站內的「儲存設定」寫入私人「網站模型」A1:K100；其他裝置重新讀取後會取得相同設定。包含顏色、項目、月份覆寫、資產與退休情境。
- 開啟頁面時每 60 秒重新讀取來源；頁面隱藏時暫停，授權過期需重新登入。
- 儲存前比對上次讀取版本，發現雲端已變動時拒絕覆蓋；未儲存草稿不會被定時刷新取代。
- Google 登入維持測試模式，僅指定測試帳號能登入。試算表分享設定未公開。

部署使用 GitHub Actions，需 PAGES_READY=true 且公開識別碼已設定。不得把本機含私人資料的預覽 HTML 上傳到本儲存庫。
